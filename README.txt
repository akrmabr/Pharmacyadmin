لوحة إدارة تراخيص النجاح — نسخة PWA

التحديثات:
- الدخول أصبح بحساب Supabase Auth الحقيقي: البريد + كلمة المرور.
- رابط المشروع محفوظ داخل التطبيق ولا يظهر للمستخدم.
- إصدار سنوي بتاريخ انتهاء يختاره المدير.
- إصدار مدى الحياة.
- تمديد ترخيص حتى تاريخ يحدده المدير.

التجهيز مرة واحدة:
1. ارفع ملفات اللوحة إلى استضافة HTTPS.
2. أنشئ مستخدمًا في Supabase Authentication > Users.
3. أضف نفس المستخدم إلى public.platform_admins.
4. استخدم بريده وكلمة مروره في اللوحة.

الملفات الخلفية:
- owner-dashboard
- owner-control
- license-check (لا تعدّلها)

مهم: لا تستخدم service_role داخل الواجهة. لا تحتاج لرمز OWNER_ADMIN_TOKEN؛ هذه النسخة تستخدم Access Token حقيقي من Supabase Auth.
